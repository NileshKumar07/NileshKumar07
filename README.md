## 🚀 Flagship Projects

### 🦯 **Smart Cane 2025** — AI-Powered Safety for the Visually Impaired

<div align="center">

![Impact](https://img.shields.io/badge/Impact-Real_World_Tested-blue?style=flat-square)
![Tech](https://img.shields.io/badge/Tech-AI_+_IoT-purple?style=flat-square)

</div>

An **AI-powered safety cane** designed to empower visually impaired individuals with independence and safety.

**✨ Key Features:**
- 🗣️ **AI Voice Navigation** — Step-by-step audio guidance
- 🚧 **Obstacle Detection** — LiDAR + Ultrasonic sensors
- 🚦 **Traffic Light Detection** — Computer vision integration
- 🚨 **Fall Detection + Auto SOS** — Emergency response system
- 📍 **Live GPS Tracking** — Real-time location sharing
- 🌤️ **Weather-Aware Routing** — Adaptive path suggestions
- 📳 **Haptic + Audio Feedback** — Multi-sensory alerts
